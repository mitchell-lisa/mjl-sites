# Bella Ciao Pizza, sample redesign

Relationship preview of Bella Ciao Pizza LLC for Mitchell Lisa (LC-326). Mobile wood-fired pizza in Dayton and South Brunswick, NJ.

This is **not** the official website. It is **not affiliated** with Bella Ciao Pizza LLC.

## Open the site

```bash
cd bella-ciao-pizza
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

Production build:

```bash
npm run build
npm start
```

## Live preview

Share URL: https://mjl-bella-ciao-pizza.vercel.app

Root Directory is `bella-ciao-pizza`. The preview banner and `noindex` / `robots.txt` Disallow stay on. There are no forms.
